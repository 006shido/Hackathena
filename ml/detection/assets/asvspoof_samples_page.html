ASVspoof 2019 database¶

Messages¶

This page only hosts audio samples from ASVspoof2019 LA database.

  • Paper on the database, Elsevier version and arxiv version;

  • Database on Datashare. DOI: https://doi.org/10.7488/ds/298

  • ASVspoof2019 website;

ASVspoof 2019 database comes with The Open Data Commons Attribution License. Please follow the license when using samples on this webpage.

Please cite the following papers if you use ASVspoof 2019 database for your research:

Todisco, M. et al. ASVspoof 2019: future horizons in spoofed and fake audio detection. in Proc. Interspeech 1008–1012 (2019). doi:10.21437/Interspeech.2019-2249

Wang, X. et al. ASVspoof 2019: A large-scale public database of synthesized, converted and replayed speech. Comput. Speech Lang. 64, 101114 (2020), doi:10.1016/j.csl.2020.101114
